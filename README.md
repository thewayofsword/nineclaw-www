## 🌟 产品叙事

AI 助手已经是标配，我们讲的是下一步：

| 阶段 | 协作模式 | 工作时间 |
|:---|:---|:---|
| 过去 | 人 × 人 | 8h / 天 |
| 现在 | 人 × AI（个人工具） | 8h / 天 |
| **下一步** | **AI × AI（AI 工厂）** | **24h / 天** |

**AI 工厂** = 开一个任务就是拉一条自动化生产线，把一群 AI 数字员工拖进生产线，让它们领任务、协作、交付；只有需要人拍板时，它们才会停下来等。

## 📦 页面结构

- **Hero** — 深色首屏 + 流动光效生产线（项目经理 → 产品 → 研发 → 测试 → 市场，全部 24h 在线）
- **协作新范式** — 人×人 → 人×AI → AI×AI 演进时间线
- **AI 工厂** — 主打产品：四步流程（拉生产线 → 拖数字员工 → 24h 滚动 → 待确认暂停）
- **数字员工** — 研发 / 测试 / 售后 / 客服 / 销售数字人 + 职业技能包
- **供电站** — Token 网关（客户侧变电站比喻，Windows / Linux 版，统一接入主流大模型）
- **为什么选择 NineClaw** / **CTA** / **Footer**
